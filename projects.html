Academic Project

Train System Simulation / Cargo Tracker

A Java-based data structures project designed around a train system simulation. The project demonstrates object-oriented programming, inheritance, polymorphism, collections, searching, sorting, trees, maps, and graph algorithms.

Java
OOP
AVL Tree
HashMap
Graphs

Overview

This project was built as a full Java simulation where different train cars, passengers, cargo, and routes are modeled using object-oriented design and advanced data structures.

What I Worked On

  • Created multiple train car classes using inheritance and polymorphism.
  • Used collections such as ArrayList, LinkedList, Queue, and HashMap.
  • Implemented sorting and recursive binary search.
  • Used an AVL tree to index train cars by car ID.
  • Built graph-based station routes using Dijkstra’s shortest path algorithm and Prim’s minimum spanning tree algorithm.

Why It Matters

This project helped me connect classroom data structures to a more realistic software system. Instead of only learning the structures separately, I practiced using them together inside one larger simulation.
