Academic Project

Hogwarts Train System

A Java-based data structures project designed around a Hogwarts-inspired train system simulation. The project demonstrates object-oriented programming, inheritance, polymorphism, collections, searching, sorting, trees, maps, and graph algorithms.

Java
OOP
AVL Tree
HashMap
Graphs

Problem

The Hogwarts Train System was built to solve a learning problem: data structures can feel disconnected when they are only practiced in small isolated examples.

What I Worked On

  • Created multiple train car classes using inheritance and polymorphism.
  • Used collections such as ArrayList, LinkedList, Queue, and HashMap.
  • Implemented sorting and recursive binary search.
  • Used an AVL tree to index train cars by car ID.
  • Built graph-based station routes using Dijkstra’s shortest path algorithm and Prim’s minimum spanning tree algorithm.

Our Approach

I structured the project as a themed simulation so data structures could work together inside one larger system.

Technical Deep Dive

The project combines object models, collections, sorting, searching, tree indexing, and graph algorithms.

How Did It End

This project concluded as one of my strongest academic demonstrations of data structures in a complete Java system.

Why It Matters

This project helped me connect classroom data structures to a more realistic software system.
