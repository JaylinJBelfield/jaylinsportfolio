Academic Project

Hogwarts Train System

A Java-based data structures project designed around a Hogwarts-inspired train system simulation. The project demonstrates object-oriented programming, inheritance, polymorphism, collections, searching, sorting, trees, maps, and graph algorithms.

Overview

The Hogwarts Train System is a Java simulation that models train cars, passengers, cargo, and station routes using object-oriented programming and advanced data structures. It was built as a multi-phase academic project to show how different programming concepts can work together inside one larger system.

What I Worked On

  • Created multiple train car classes using inheritance and polymorphism.
  • Used collections such as ArrayList, LinkedList, Queue, and HashMap.
  • Implemented sorting and recursive binary search.
  • Used an AVL tree to index train cars by car ID.
  • Built graph-based station routes using Dijkstra’s shortest path algorithm and Prim’s minimum spanning tree algorithm.

Why It Matters

This project helped me connect classroom data structures to a more realistic software system. Instead of only learning each structure separately, I practiced using them together inside one larger simulation with objects, routes, searches, sorting, and system behavior.
